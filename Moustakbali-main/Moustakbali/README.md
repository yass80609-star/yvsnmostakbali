# Moustakbali — Livraison finale

## Structure
```
moustakbali-delivery/
├── frontend/   ← La plateforme complète (votre code + assistant IA intégré)
└── backend/    ← Serveur IA (chat + transcription vocale)
```

## Lancer le projet

### 1. Backend (serveur IA)
```bash
cd backend
npm install
npm start        # http://localhost:5000
```
Le fichier `.env` est déjà inclus avec toutes les clés.

### 2. Frontend (plateforme)
```bash
cd frontend
npm install
npm run dev      # http://localhost:5173
```

## Comment utiliser l'assistant IA
1. Connectez-vous sur la plateforme
2. Allez sur le Dashboard
3. Cliquez sur l'icône ✦ (Sparkles) dans la barre du haut
4. La fenêtre de chat apparaît en bas à droite
5. Cliquez sur ⤢ pour agrandir en mode centré
